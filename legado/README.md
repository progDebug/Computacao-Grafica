# Repositório de Computação Gráfica

Este repositório tem como objetivo armazenar todo o código fonte desenvolvido para as atividades da disciplina de Computação Gráfica da faculdade.

Aqui serão mantidos os projetos, exercícios e experimentos realizados ao longo do curso, servindo como registro e apoio para estudos futuros.

Tarefa atual:
5. ter funções para corretamente aplicar transformações de translação, rotação e de escala sobre
objetos 3D;
6. ter teclas do teclado associadas a comandos para transladar, rotacionar e escalonar o objeto nos
três eixos (X, Y e Z). Isso significa a definição de, pelo menos, 18 teclas se consideramos
incrementos e decrementos de valores em cada eixo e para cada tipo de transformação. Configure
também a tecla F1 para mostrar uma mensagem de ajuda na tela descrevendo as teclas de
movimentação
